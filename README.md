# decodia-legal

Public Privacy Policy, Terms of Use and Support pages for Decodia (by NoxTri), served with GitHub
Pages (Settings → Pages → Deploy from a branch → default branch / root).

- https://busrahekim.github.io/decodia-legal/privacy/
- https://busrahekim.github.io/decodia-legal/terms/
- https://busrahekim.github.io/decodia-legal/support/

The source of truth is the `legal-site/` folder of the Decodia repository; copy it here when it
changes.
